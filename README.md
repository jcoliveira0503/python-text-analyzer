# Python Text Analyzer

A lightweight command-line tool that analyzes text and returns basic statistics.

## Features
- Character count
- Word count
- Sentence count
- Average words per sentence
- Most common words
- Basic support for accented Latin characters

## Technologies
Python · Regular Expressions · Collections

## Run
```bash
python text_analyzer.py
```

## Skills demonstrated
Python fundamentals · Text processing · Data structures · Problem solving
